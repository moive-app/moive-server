## 구현 API

### `POST /api/meetings` — 모임 생성

- 인증 필요 (JWT Bearer)
- 모임장이 생성 즉시 `participants`에 `COND_PENDING` 상태로 자동 등록
- `participant_cnt` 초기값 1 (모임장 포함)
- 초대 코드: 8자리 대문자 영숫자, `SecureRandom` 생성, 중복 시 재생성
- 초대 URL: `https://moive.app/invite/{inviteCode}`
- 생성 직후 `status`는 항상 `CONDITION_INPUT`

**검증 로직 (서비스에서 직접 처리)**

| 조건 | 에러코드 |
|------|---------|
| name이 null 또는 공백만 | `MEETING_NAME_EMPTY` (4001) |
| trim 후 20자 초과 | `MEETING_NAME_TOO_LONG` (4002) |
| hasSchedule=true인데 date 또는 time 누락 | `MEETING_SCHEDULE_INCOMPLETE` (4003) |
| purposeType이 null 또는 유효하지 않은 값 | `MEETING_PURPOSE_EMPTY` (4004) |

---

### `POST /api/meetings/invite/{inviteCode}/join` — 초대 참여

- 인증 필요 (JWT Bearer)
- Idempotent: 이미 활성 참여자면 기존 상태 그대로 반환 (`alreadyParticipant: true`)
- 탈퇴 후 재참여: 신규 참여자와 동일하게 처리 (새 Participant 레코드 생성)

**참여자 상태 결정 (모임 status 기준)**

| 모임 status | 부여 participantState |
|------------|----------------------|
| `CONDITION_INPUT` | `COND_PENDING` |
| `VOTING` | `NEW_RESTRICTED` |
| `CONFIRMED` | `NEW_RESTRICTED` |
| `COMPLETED` | 참여 불가 (400) |

**에러코드**

| 조건 | 에러코드 |
|------|---------|
| inviteCode 미존재 | `INVALID_INVITE_CODE` (4041) |
| 모임 미존재 | `MEETING_NOT_FOUND` (4042) |
| 정원 10명 초과 | `MEETING_FULL` (4001) |
| 모임 COMPLETED | `MEETING_COMPLETED` (4002) |
